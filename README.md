# 全文伴读 · Context Translator

使用自己的大模型 API，把网页、在线 PDF 和本地文字型 PDF 翻译成简体中文。一次点击覆盖全文，结合正文上下文分批生成译文，在原文下方逐段展示。

基于 Chrome Manifest V3，无账号系统、无自建后端。本项目面向个人阅读技术文档和论文，当前版本为 **0.2.1**。

## 功能

| 功能 | 支持情况 |
| --- | --- |
| 网页双语阅读 | 标题、正文、列表、图注及表格自然语言，原文下方显示译文 |
| 全文上下文 | 容量足够时每批携带全文，超限时使用章节和相邻内容 |
| 动态补译 | 自动处理启动后新增或修改的正文 |
| PDF | 在线链接、本地文件、全文提取、逐页原版预览 |
| 阅读浮窗 | 拖动、折叠、显示／隐藏译文、停止、失败重试 |
| 自带模型 | 自定义 API Key、HTTP(S) Base URL、模型名称 |
| 本地缓存 | 复用已翻译段落，在设置页清空 |
| 高亮批注 | 选取同一译文段落内的任意文字，高亮、编辑或删除批注 |
| 长期保存 | 批注独立存储，不随译文缓存清空或自动淘汰 |
| Markdown 导出 | 当前文档的双语全文＋批注，或仅批注摘录 |

## 0.2.1 修复：代码占位符与批量失败

- 按段落校验并显示成功译文，单段占位符损坏、重复或漏译不再拖累同批其他段落；只重试失败项。
- 若模型持续改写代码／公式占位符，自动结合原段落及正文上下文翻译占位符之间的文字，由插件原样拼回代码和公式。所有文字片段都通过校验后才显示整段，不接受缺失片段。
- 长段切分后，每个待译片段只携带属于自己的占位符说明，减少模型误补其他代码的机会。

升级后在扩展管理页重新加载插件，再刷新原网页并点击「翻译全文」。提示词版本已更新，旧译文缓存不会复用；批注保留。

## 0.2.0 更新：高亮批注与导出

网页和 PDF 阅读器都支持中文译文批注与 Markdown 导出。批注在同一 Chrome 用户资料中持久保存，没有自动过期时间。

### 添加、查看和修改批注

1. 在**一段中文译文内**用鼠标选择几个字、一句话或整段，点击浮出的「添加批注」。不支持跨段落选择或在原文中添加批注。
2. 输入批注后保存，选中文字呈黄色背景；也可以留空，只保存高亮。
3. 点击高亮查看、编辑或删除批注。重叠高亮会列出对应批注供选择。
4. 点击浮窗或 PDF 工具栏中的「批注 / 导出」，可查看当前文档全部批注。

网页刷新或重开后，会自动恢复已批注段落的保存时译文与高亮，**不会自动调用模型**。其他段落需点击「翻译全文」继续翻译。网页地址按完整 URL（不含 `#` 片段）识别，查询参数不同视为不同文档。

本地 PDF 再次选择同一文件时恢复批注；身份按文件内容识别，所以文件改名后仍可恢复。相同字节内容的在线 PDF 和本地 PDF 共用批注；文件内容改变后视为新文档。

重新翻译时，只有原文段落、完整译文和选区都匹配，才恢复对应高亮；无法匹配的批注显示为「未定位」，仍可查看、编辑、删除和导出。网页重开后优先恢复批注保存时的译文快照，不意味着该译文是模型刚生成的最新版本。

### 导出 Markdown

在「批注 / 导出」面板选择：

- **导出双语全文**：当前已提取正文按段落列出原文、译文及批注，包含标题、来源和导出时间。没有完成翻译的段落会明确标注；未定位的批注也会保留。
- **导出批注摘录**：仅包含选中的译文、批注内容和来源；只有高亮的记录也会导出。

生成的 `.md` 文件通过浏览器下载。Markdown 保留文字内容和段落对应关系，不还原原网页版式、图像或 PDF 图表；代码和公式的可提取文本会保留。导出的 Markdown 可供阅读和备份，目前不支持将其导入回插件。

### 保存边界

批注与译文缓存分开保存，不因清空缓存、缓存条数上限、关闭浏览器或正常覆盖升级而删除。**卸载扩展、清除扩展数据、删除 Chrome 用户资料或损坏本机存储仍会丢失批注**；重要批注请定期导出。没有云同步，不同 Chrome 用户资料不会自动共享数据。

本版新增 `unlimitedStorage` 权限用于长期保存批注。更新仍使用原扩展目录覆盖并重新加载；不要卸载重装，以保留已保存的数据。

## 从源码快速开始

需要 **Chrome 130+**，构建环境需要 **Node.js 22.13+（22 系列）或 24+** 和 npm。建议使用 Node.js 24 LTS。

```sh
git clone https://github.com/TJR9098/context-translator.git
cd context-translator
npm ci
npm run build
```

构建完成后，将生成的 `dist` 文件夹加载到 Chrome，步骤见下方。仓库不提交 `dist`、`node_modules`、测试浏览器资料或安装压缩包；首次克隆需要先构建。

## 安装

1. 打开 Chrome，在地址栏输入 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目的 **`dist` 文件夹**，该文件夹内有 `manifest.json`。
4. 在 Chrome 的扩展菜单中找到「全文伴读」，可点击图钉固定到工具栏。
5. 打开插件的「模型设置」，填写 Base URL、API Key、模型名称，点击「保存设置」。可使用「测试连接」发送一个短请求。

构建后的 `dist` 包含 PDF.js 及其字体和解析资源，加载插件不需要运行服务器。如果已有安装压缩包，先解压再选择其中的 `dist`，此时无需安装 Node.js。

## 模型配置

- 默认 Base URL：`https://api.deepseek.com`。
- 默认模型名称：`deepseek-flash`。可改成你的服务实际支持的 Chat Completions 模型。
- 地址可以是服务根地址、带 `/v1` 的地址，或完整的 `/chat/completions` 端点，不会重复追加路径。
- 本机和远程服务均支持 HTTP / HTTPS，也支持自定义端口。
- 「长文与缓存设置」中可调整上下文容量和输出上限。默认上下文 1,048,576 tokens、单批输出 8,192 tokens。**如果使用其他模型或中转服务，请按该服务的实际限制修改。**
- 模型须能按提示返回 JSON。插件不强制接口支持 `response_format` 参数，兼容只支持基础 Chat Completions 的服务。DeepSeek 官方接口默认关闭思考模式用于忠实翻译；自定义接口不发送这一专属参数。

Key 仅保存在本机扩展存储中，不放进网页、不写入代码、不通过浏览器同步。译文缓存也保存在本地，可在设置中清空。

## 网页阅读

1. 打开文章，点击插件图标，再点击「翻译当前网页 / PDF」。
2. 页面右下角出现进度与操作栏。已完成的译文直接出现在对应原文下方。
3. 关闭插件弹窗后翻译继续。可以停止、隐藏／显示译文、重试失败段落。拖动浮窗标题可移动位置，点击「折叠／展开」可收起或恢复操作栏；折叠不会中断翻译。
4. 本页面后续加载或修改的正文会自动补译。切换到新文章后重新点击「翻译全文」。

正文识别优先选择文章或主内容区域；翻译标题、段落、列表、图注、表格的自然语言。跳过导航、侧栏、页脚、代码块、常见评论区域。代码、公式和内联代码保留原样。原网页本身不被替换。

## PDF 阅读

- **在线 PDF**：在 PDF 标签页中点击插件翻译，或打开「PDF 阅读器」粘贴链接并点击「加载链接」。从插件的当前页面翻译入口打开时，完成全文读取后自动开始翻译。
- **本地 PDF**：打开「PDF 阅读器」，点击「选择本地 PDF」，读取完成后点击「翻译全文」。不需要授予「允许访问文件网址」。
- PDF 在插件阅读页重新排版，按原文段落和译文对照展示。先读取所有页面，随后启动分批翻译。
- 每一页都有「查看本页原版」，在本地渲染该页图表、公式和排版供核对。
- 未提取到文本的页面会单独提示；扫描件、图片 OCR、密码保护文件解锁、原版双语 PDF 导出不在本版范围内。

PDF 文本层的质量会影响提取结果。双栏顺序和断行做了几何重排，但复杂表格、数学公式和混合版式仍可能出现文本顺序问题；请用原版预览核对。原始文件不会被修改。

## 上下文与质量策略

一次启动覆盖全部已提取正文，不按视口懒翻译。每批生成适量译文，减少输出截断和段落错位。

1. 能容纳时，每一批请求都附带完整正文，以及内联代码／公式占位符对应的原始内容。
2. 若超过配置的上下文容量，则保留标题、目录信息、共享术语表和目标段落，优先加入同章节及相邻段落。进度栏明确显示「章节上下文」。所有目标段落仍会进入翻译队列，不会只翻译文档前部。
3. 对 token 使用 UTF-8 字节数作保守估算，并预留输出与消息开销。因此某些实际上放得下的文本可能提前进入章节模式。
4. 校验段落编号、非空译文和代码／公式占位符。有效段落立即显示，缺失或错误段落自动重试一次；持续损坏占位符时再自动补译文字片段并原样拼回代码。补译仍不完整则标记失败。JSON 损坏、未知编号或输出截断不接收该响应。
5. 生成过程维护最多 100 项共享术语。缓存按接口、模型、提示词版本、文档来源、章节、原文和占位内容区分，最多保留 1,500 段。需要重新生成已有译文时先清空缓存。

这些检查保证结构可核对，不能代替对译文语义准确性的判断。已通过真实 `deepseek-flash` 冒烟测试：短网页与本地 PDF 各 3 段产生中文译文，段落对应正确，内联代码保持原样。长论文及错误恢复流程使用模拟接口验证，不代表对整篇论文译文质量的评测。真实测试密钥未包含在代码或安装包中。

## 权限与运行方式

- `activeTab` / `scripting`：点击按钮后读取当前网页并插入译文。
- `storage`：本机配置。
- `unlimitedStorage`：允许在本机长期保存批注与对应译文快照；批注没有自动淘汰策略。
- `offscreen`：创建独立 Worker 运行长请求，避免弹窗关闭或 service worker 空闲回收中断模型生成。
- HTTP(S) 站点权限：访问你自定义的 API 地址和在线 PDF。不会自动翻译浏览记录或后台标签页。

网页内容脚本会在页面打开时检查并恢复该页面已有的本机批注。只有用户点击翻译按钮才会启动模型调用。批注和用户写的笔记不会作为翻译上下文发送给模型。

PDF 解析在本机完成；点击翻译后，提取出的正文发到所配置的 API。关闭网页／阅读器会结束该页面的翻译任务；重新打开可复用已有缓存。浏览器重启不自动恢复任务。

跨域 iframe、浏览器内部页面、Canvas 内绘制的正文、Shadow DOM 内正文，以及网站特殊排版不保证覆盖。在线 PDF 若需登录或受服务器限制，可先下载文件再从本地选择。

浏览器集成测试使用隔离的 Chrome for Testing 配置与本机模拟接口，不需要真实密钥：

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = Join-Path (Get-Location) '.test-browsers'
npx playwright install chromium
npm run test:browser
```

macOS / Linux 可使用以下等价命令：

```sh
PLAYWRIGHT_BROWSERS_PATH="$PWD/.test-browsers" npx playwright install chromium
npm run test:browser
```

浏览器测试前须先 `npm run build`。浏览器安装目录默认使用项目内的 `.test-browsers`，测试不读取日常浏览器配置。

布局与浮窗专项测试：`npm run test:layout`。设置 `$env:LIVE_SITES = '1'` 可同时检查本次修复的 Microsoft 与 Anthropic 实际页面，翻译仍使用本机模拟接口。

可选：指定一份真实论文，或访问需求中提供的三个实际文章页面：

```powershell
$env:REAL_PDF_PATH = 'C:\path\paper.pdf'
$env:LIVE_SITES = '1'
npm run test:browser
```

真实 API 冒烟测试脚本为 `tests/live-smoke.mjs`，从 `CT_SMOKE_API_KEY` 环境变量读取密钥，可通过 `CT_SMOKE_MODEL` / `CT_SMOKE_BASE_URL` 覆盖模型和地址。设置这些环境变量后执行 `node tests/live-smoke.mjs`。该测试会产生真实调用费用；执行前需先运行集成测试生成 PDF 测试样本。测试完成后清除配置并删除隔离浏览器资料。报告 `test-results/live-api-report.json` 不包含密钥。不要将真实 Key 填入源码或提交到 Git。

详细验证范围见 [TESTING.md](TESTING.md)。其中提到的截图与 JSON 报告属于本地测试产物，克隆后运行对应测试可重新生成。

## 常见问题

**修改或升级插件后，页面仍显示旧版界面。** 重新构建并在扩展管理页点击重新加载，然后刷新网页。已打开页面中的内容脚本不会随构建自动替换。

**接口报 401、404 或 400。** 分别检查密钥、Base URL／模型名称，以及模型上下文容量和输出参数。先用设置页的「测试连接」验证接口。

**长文显示「章节上下文」。** 正文超过配置容量的保守估算。这不会跳过文档后部；每段仍会进入翻译队列。确认模型确实支持后，可提高配置的上下文容量。

**译文需要重新生成。** 在模型设置中清空译文缓存，再点击「翻译全文」。

**PDF 加载失败或文本顺序异常。** 在线文件可先下载再选择本地文件；扫描件没有可提取的文本层，不支持 OCR。复杂图表和公式请通过「查看本页原版」核对。
